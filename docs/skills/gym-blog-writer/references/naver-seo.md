# 네이버 검색 알고리즘 지식 베이스

> **기준일: 2026-07-23** — 이 문서의 기준일이 3개월 이상 지났거나, 사용자가 "노출이 떨어졌다", "알고리즘이 바뀌었다"고 말하면 **글 쓰기 전에 웹 검색으로 최신 변화를 확인**하고, 이 문서와 다른 점이 있으면 최신 정보를 우선 적용한 뒤 사용자에게 지식 베이스 갱신을 제안한다.

네이버는 "저품질 블로그"라는 개념을 공식적으로는 부인하지만, 의심 콘텐츠를 자체 시스템에서 후순위로 걸러낸다. 아래는 공식 발표(✓)와 실무 검증 통설(≈)을 구분해 정리한 것이다.

---

## 1. 랭킹 알고리즘 3층 구조

**✓ C-Rank (출처 신뢰도)** — 문서가 아니라 **블로그 자체**를 평가한다. 한 주제로 꾸준히 양질의 글을 쌓은 블로그의 글이 상위에 간다. 2025~26년 들어 **주제 집중도**가 핵심 평가요소로 강화됨.
→ 실무 의미: 헬스·운동·지역생활 범위를 벗어난 글을 섞지 않는다. 카테고리는 2~3개 이내로 집중.

**✓ D.I.A. / D.I.A.+ (문서 품질·의도 분석)** — 개별 문서의 경험·정보성·검색 의도 부합을 본다. 직접 경험(운영자의 실제 시설·운영 이야기)이 들어간 글, 문서의 맥락이 검색 의도와 맞는 글에 가산. 영상 삽입 문서 가산점.
→ 실무 의미: "검색한 사람이 알고 싶은 것"에 실제로 답해야 한다. 홍보만 있고 정보가 없으면 감점.

**✓ 에어서치·스마트블록** — AI가 검색어를 의도 단위로 쪼개 블록별로 노출한다("○○동 헬스장" → 가격·후기·시설 등). 통합검색 1페이지 개념이 약해지고, **구체적 의도를 가진 세부 키워드**에 걸릴 기회가 늘었다.
→ 실무 의미: 제목에 메인 키워드 + 세부 의도(예: "새벽 운동", "여성전용")를 함께 담으면 스마트블록 진입에 유리.

## 2. 지수 향상 조건 (가산 요소)

| 요소 | 내용 | 근거 |
|---|---|---|
| 체류시간 | 지수 가산 중 가장 빠른 요소. C-Rank와 D.I.A. 양쪽에 가산. 발행 후 24시간~7일 사이 누적이 중요 | ≈ |
| 주제 일관성 | 한 주제로 쌓인 글 → C-Rank 상승. 협찬·기자단 글도 주제와 안 맞으면 역효과 | ✓ |
| 발행 주기 | 주 2~3회 꾸준히. 몰아서 대량 발행은 역효과 | ≈ |
| 초기 반응 | 발행 후 24시간 내 자연스러운 조회·공감·댓글 | ≈ |
| 정보 밀도 | 검색 의도에 답하는 실질 정보. 상위글 평균 2,000~3,000자 | ≈ |
| 원본 콘텐츠 | 직접 촬영 이미지 5장 이상, 영상 30초~3분 1개 | ≈ |
| 색인 확인 | 네이버 블로그는 발행 시 자동 색인 — 서치어드바이저 요청 불필요. 제목 그대로 검색해 나오는지로 확인 | ✓ 실측 2026-08-12 |

## 3. 저품질·미노출·어뷰징 트리거 (감점·차단 요소)

| 트리거 | 내용 |
|---|---|
| 키워드 반복 | 제목·본문 과도 반복 (10회 이상 페널티 통설). 등간격 배치도 패턴 신호 |
| 유사문서 | 문장 단위 중복 판정. 같은 블로그 내 비슷한 키워드·내용 글 반복, 타 블로그와 겹치는 글, 이미지 재사용 |
| 상업성 과다 | 홍보만 있는 글 연속 발행, 상업성 외부 링크 다수, 가격·전화번호 도배 → 이탈률 상승 → 어뷰징 의심 |
| 조작 트래픽 | 매크로 공감·댓글·스크랩, 품앗이, 불량 IP. 초기 반응도 "자연스러운" 것만 |
| 금지 업종·표현 | 의료·금융 등 규제 표현, 과장·허위 (safe-expressions.md 담당) |
| 대량·복붙 발행 | 짧은 시간 다수 발행, 템플릿 복붙 글 |

**미노출 자가진단**: 발행한 글 제목을 그대로 검색해서 안 나오면 검색누락. 여러 글이 동시에 안 나오거나 순위가 일제히 밀리면 블로그 단위 감점 의심 → 발행을 늦추고 정보성 글 위주로 회복 운영.

## 4. 수치 기준표 (2026 통설)

| 항목 | 기준 |
|---|---|
| 본문 글자수 | 1,500자 이상, 상위글 평균 2,000~3,000자 |
| 제목 길이 | 30~40자 (모바일 표시 ~35자) |
| 키워드 | 메인 3~5회, 밀도 1~1.5% |
| 이미지 | 원본 5장 이상, 가로 800~1,200px, 500KB 이내 |
| 영상 | 30초~3분 1개 |
| 발행 주기 | 주 2~3회 |
| 키워드 선정 | 월 검색량 500~5,000 구간이 진입 적정 |

## 5. 블로그 운영 전략 (글 단위가 아닌 블로그 단위)

- **정보글:홍보글 비율 ≈ 2:1** — 홍보글만 연속 발행하면 상업성 과다 신호. 사이에 정보성 글(운동법·초보 가이드·지역 생활정보 등 주제 일관성 유지 범위 내)을 끼워 C-Rank를 키운다. 정보글이 키운 신뢰도를 홍보글이 수확하는 구조다.
- **같은 메인 키워드 반복 주의** — 같은 지점 글이라도 매번 "쌍용동 헬스장"만 쓰면 블로그 내 유사문서·자기잠식이 생긴다. stores.md의 지역 키워드 목록을 로테이션한다.
- **발행 직후 24시간** — 지인 공유 등 자연 유입은 좋지만, 품앗이·매크로류는 절대 금지.
- **글 발행 간격** — 동일 지점 2~3주 간격 유지(SKILL.md 규칙), 서로 다른 지점 글도 같은 날 연속 발행보다 하루 이상 간격 권장.

## 6. 이 문서의 사용법

- 글 작성 시: SKILL.md의 규칙이 이 문서를 이미 반영하고 있으므로 평소에는 SKILL.md만 따르면 된다. 이 문서는 **왜 그 규칙이 있는지**의 근거이자, 규칙에 없는 상황을 판단할 때의 기준이다.
- 기준일 경과·노출 이상 시: 상단 갱신 규칙에 따라 웹 검색으로 재분석 → 달라진 점을 사용자에게 보고 → 갱신 제안.
