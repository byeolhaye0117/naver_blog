# 발행 기록 (post log)

글 간 유사성 방지용 장부. 글을 쓸 때마다 한 줄씩 쌓는다.

스킬 파일을 직접 수정할 수 없는 환경에서는 이 파일이 비어 있을 수 있다. 그 경우 글 완성 시 출력되는 기록 한 줄을 **사용자가 보관**했다가, 다음 글 요청 때 함께 붙여넣는 방식으로 운영한다. 사용자가 붙여넣은 기록은 이 파일의 기록과 동일하게 취급한다.

**형식:**
```
날짜 | 지점 | 메인 키워드 | 도입 유형 | 주력 앵글 | 소제목 목록
```

**예시:**
```
2026-07-23 | 쌍용점 | 쌍용동 헬스장 | 도입④상황묘사 | 앵글:시간 | 새벽 5시에도 불이 켜져 있는 이유, 기다리는 시간이 없어야 운동이 됩니다, ...
```
