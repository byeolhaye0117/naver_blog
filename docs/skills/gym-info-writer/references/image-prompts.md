# 문단별 이미지 프롬프트 생성 (image prompt bank)

정보글의 **각 소제목(문단)마다 그 문단을 대표하는 실사 사진 프롬프트**를 한 개씩 만든다. 미드저니·DALL·E 등 범용 이미지 생성기에 그대로 붙여넣을 수 있는 **한글 프롬프트**를 출력한다. 목적은 두 가지다: ①직접 촬영이 어려울 때 참고할 이미지를 만들거나, ②직접 촬영 시 어떤 구도로 찍을지 잡는 가이드.

**기본 스타일 = 실사 사진(헬스장 현장 느낌).** 일러스트·3D·그래픽 톤이 아니라, 실제 헬스장에서 찍은 듯한 자연스러운 사진. 프롬프트에 매번 이 톤을 명시한다.

---

## 언제 만드나
- 정보글 초안이 완성되면, **소제목(문단)마다 프롬프트 1개씩** + **대표이미지(첫 이미지) 프롬프트 1개**를 함께 낸다.
- 즉 소제목 4~5개짜리 글이면 프롬프트는 대표이미지 포함 **총 5~6개**.
- 글 본문의 이미지 배치 규칙(각 소제목 바로 위 1장)과 1:1로 대응한다.

## 프롬프트 구성 공식 (한 줄에 이 순서로)
`[피사체·행동] + [헬스장 공간/맥락] + [구도·앵글] + [조명·분위기] + [실사 사진 품질 태그]`

- **피사체·행동**: 그 문단이 말하는 내용을 한 장면으로. (예: "스쿼트 자세를 잡는 20대 여성", "덤벨을 정리하는 트레이너의 손")
- **공간/맥락**: 지점 특징과 연결(stores.md). 실내 헬스장, 프리웨이트 존, 유산소 존, 스트레칭 매트 등.
- **구도·앵글**: 클로즈업 / 미디엄샷 / 로우앵글 / 측면 등. 대표이미지는 시선을 끄는 구도.
- **조명·분위기**: "자연광이 드는", "따뜻한 실내조명", "아침 햇살" 등. 헬스장답게 밝고 청결한 톤 기본.
- **품질 태그(항상 포함)**: `실사 사진, 고해상도, 자연스러운 조명, 광고 사진 느낌, 세로 4:5` (미드저니면 `--ar 4:5 --style raw` 병기 가능).

## 실사 톤 고정 규칙 (매 프롬프트 필수)
- 앞에: "실제 헬스장에서 촬영한 듯한 자연스러운 실사 사진,"
- 뒤에: "일러스트·CG·과장된 색감 없이 사실적으로, 고해상도 DSLR 사진 느낌."
- **금지**: 만화체·3D 렌더·일러스트·수채화·네온 판타지 톤. (정보글 신뢰도를 깎음)

## 인물·저작권·안전
- **특정 실존 인물·유명인 묘사 금지.** "20대 여성", "30대 남성 회원", "트레이너" 등 익명·일반형으로.
- **얼굴 클로즈업보다 동작·손·자세 중심**을 권장(초상권·유사문서 위험 완화, 직접 촬영 대체도 쉬움).
- 브랜드 로고·상표·특정 상표 기구명은 프롬프트에 넣지 않는다.
- 노출·선정적 구도 금지. 운동복은 일반적이고 단정하게.
- 여성전용 지점(성정점·용곡점)이면 남성 피사체를 넣지 않는다(stores.md 확인).

## 대표이미지(첫 이미지) 프롬프트 규칙
- 검색 썸네일용. "이 글이 내 궁금증에 답한다"를 신호하는 장면.
- 가격 배너·이벤트 배지·텍스트 오버레이 금지(정보글엔 홍보 신호가 역효과 — SKILL 본문 규칙과 동일).
- 정보 키워드 소재를 한 장면으로 압축(예: 정체기 글이면 체중계 위 발 클로즈업 + 고민하는 분위기).

## 출력 형식
정보글 본문 아래에 **"■ 문단별 이미지 프롬프트"** 블록으로 모아서 낸다. 각 줄은:

```
[대표이미지] 실제 헬스장에서 촬영한 듯한 자연스러운 실사 사진, (장면·구도·조명), 실사 사진 고해상도 DSLR 느낌, 세로 4:5
[소제목1: "실제 소제목 문구"] 실제 헬스장에서 촬영한 듯한 자연스러운 실사 사진, (장면·구도·조명), …
[소제목2: "…"] …
```

- 본문의 `[이미지: 설명]` 자리와 순서가 일치해야 한다.
- 프롬프트 끝에 파일명·대체텍스트 안내를 1회 덧붙인다(정보 키워드+지역 키워드 포함 권장 — SKILL 이미지 규칙과 연결).

## 예시 (다이어트 정체기 글, 실사 톤)
- `[대표이미지] 실제 헬스장에서 촬영한 듯한 자연스러운 실사 사진, 체중계 위에 올라선 사람의 발과 종아리 클로즈업, 밝은 실내 자연광, 잔잔하고 사색적인 분위기, 일러스트·CG 없이 사실적으로, 고해상도 DSLR 느낌, 세로 4:5`
- `[소제목: "정체기 3주째라면 이것부터"] 실제 헬스장에서 촬영한 듯한 자연스러운 실사 사진, 운동 노트에 식단을 적는 30대 여성의 손 클로즈업, 프리웨이트 존 배경 흐림, 따뜻한 실내조명, 사실적으로, 고해상도 DSLR 느낌, 세로 4:5`
- `[소제목: "유산소, 시간보다 강도"] 실제 헬스장에서 촬영한 듯한 자연스러운 실사 사진, 트레드밀에서 걷는 사람의 측면 미디엄샷, 유산소 존, 아침 햇살, 사실적으로, 고해상도 DSLR 느낌, 세로 4:5`
