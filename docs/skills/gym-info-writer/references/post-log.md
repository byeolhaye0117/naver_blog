# 발행 기록 (post log) — gym-blog-writer와 공유

글 간 유사성 방지 + 정보글:홍보글 2:1 균형 관리용 장부. 홍보글·정보글을 한 장부에 함께 쌓아 균형을 본다.

스킬 파일을 직접 수정할 수 없는 환경에서는 이 파일이 비어 있을 수 있다. 그 경우 글 완성 시 출력되는 기록 한 줄을 **사용자가 보관**했다가, 다음 글 요청 때 붙여넣는 방식으로 운영한다. 사용자가 붙여넣은 기록은 이 파일의 기록과 동일하게 취급한다.

**형식 (홍보글):**
```
날짜 | 지점 | [홍보글] | 메인 키워드 | 도입 유형 | 주력 앵글 | 소제목 목록
```

**형식 (정보글):**
```
날짜 | 지점 | [정보글] | 정보KW:○○ | 지역KW:○○ | 형식 | 소재군(A~F) | 소제목 목록
```

**예시:**
```
2026-07-23 | 쌍용점 | [홍보글] | 쌍용동 헬스장 | 도입④상황묘사 | 앵글:시간 | 새벽 5시에도 불이 켜져 있는 이유, …
2026-07-24 | 쌍용점 | [정보글] | 정보KW:다이어트 정체기 극복 | 지역KW:쌍용동 헬스장 | 형식③오해정정 | 소재B | 정체기 3주째라면 이것부터, …
```

---

## 균형 점검
- 새 글을 쓰기 전 최근 기록을 훑어 **정보글:홍보글이 2:1 근처인지** 확인한다. 홍보글이 연속되면 다음은 정보글을 권한다.
- 같은 지점에서 소재·키워드·형식이 최근 글과 겹치지 않게 고른다.
