# 정보글 소재·각도 은행 (topic bank)

정보글의 소재와 정보 키워드를 로테이션하기 위한 목록. 사용자가 주제만 던지거나 "아무 정보글이나" 요청하면 여기서 골라 제안한다. 같은 지점에 같은 소재·같은 정보 키워드를 반복하지 않는다(자기잠식 방지). 헬스·운동·다이어트·건강습관 범위를 벗어나지 않는다(C-Rank 주제 일관성).

각 소재에는 예시 정보 키워드를 달아둔다. 실제 키워드는 네이버 연관검색어·자동완성으로 검증해 월 검색량 500~5,000 구간(naver-seo.md §4)을 노리는 게 좋다.

## A. 초보 진입 (진입장벽 낮추기 — 등록 직전 독자층)
- 헬스장 처음 갔을 때 순서 / 정보KW: `헬스 초보 운동 순서`, `헬스장 처음`
- 웨이트 기구 사용법 기초 / `헬스 기구 사용법`, `프리웨이트 초보`
- 운동 전후 스트레칭 / `운동 전 스트레칭`, `운동 후 스트레칭`
- 혼자 운동 루틴 짜기 / `헬스 초보 루틴`, `초보 운동 계획`
- 운동 강도·세트·횟수 기초 / `초보 세트 횟수`, `근력운동 강도`

## B. 다이어트 (효과보장 표현 최고 주의 — safe-expressions.md B)
- 직장인 다이어트 식단 / `직장인 다이어트 식단`, `다이어트 도시락`
- 다이어트 정체기 / `다이어트 정체기 극복`, `정체기 원인`
- 공복 유산소 / `공복 유산소 효과`, `유산소 시간`
- 근손실 없이 감량 / `근손실 방지`, `다이어트 근력운동`
- 야식·폭식 관리 / `야식 끊는 법`, `폭식 후 관리`
- 칼로리·단백질 기초 / `하루 단백질 섭취량`, `다이어트 칼로리`

## C. 부위별·목적별 운동법
- 하체 운동 / `하체 운동 순서`, `스쿼트 자세`
- 등·어깨 / `등 운동 초보`, `어깨 운동 자세`
- 복근·코어 / `복근 운동`, `코어 운동`
- 힙업(여성 지점 특히) / `힙업 운동`, `여성 하체 운동`
- 자세 교정성(치료 아님·컨디셔닝으로) / `굽은 등 운동`, `거북목 운동`

## D. 시간·라이프스타일 (24시간·교대근무 강점과 자연 연결)
- 교대근무자 운동 타이밍 / `교대근무 운동`, `야간근무 운동 시간`
- 새벽 운동 vs 저녁 운동 / `새벽 운동 효과`, `저녁 운동`
- 바쁜 직장인 짧은 운동 / `직장인 운동 시간`, `30분 운동`
- 운동 습관 만들기·지속 / `운동 습관`, `헬스 꾸준히`

## E. 건강습관·부상예방
- 운동 중 부상 예방 / `운동 부상 예방`, `허리 안 아프게 운동`
- 근육통·회복 / `운동 후 근육통`, `운동 회복`
- 수면·컨디션과 운동 / `운동과 수면`
- 워밍업·쿨다운 / `운동 전 워밍업`

## F. 계절·시기 (발행 시점에 맞춰)
- 여름 전 다이어트(4~6월) / `여름 다이어트`
- 새해 운동 시작(12~1월) / `새해 운동 계획`
- 환절기·겨울 실내운동(11~2월) / `겨울 헬스`, `실내 유산소`
- 명절 후 관리 / `명절 후 다이어트`

## 여성전용 지점(성정점·용곡점·두정점) 소재 조정
- 남성 대상 표현을 쓰지 않는다. 힙업·상·하체 라인·산후·여성 초보 진입 등 여성 타겟 소재를 우선한다.
- '안심하고 운동하는 환경' 각도는 정보글에서도 자연스럽게(단, 홍보로 넘어가지 않게 정보 위주).

## 각도 고르기 원칙
- 지점 강점과 자연 연결되는 소재를 우선(쌍용점=천국의 계단 4대→유산소 소재, 여성 지점=힙업·안심 소재). 단 본문은 정보 위주로, 지점 연결은 소프트 브릿지에서만.
- 계절 소재는 발행 시점 ±1개월 안에서 고른다.
- 같은 지점 직전 정보글과 소재군(A~F)이 겹치지 않게.
