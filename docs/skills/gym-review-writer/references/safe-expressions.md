# 위험 표현 치환 가이드 (발행 전 검수용)

글 초안 완성 후 이 문서 기준으로 전체를 스캔한다. 발견된 위험 표현은 **주장 자체를 사실 기반으로 바꿔서** 치환한다.

**대원칙: 철자를 바꿔 숨기지 않는다.** "최.고", "이벤ㅌㅡ", 특수문자 끼워넣기 같은 변칙 표기는 그 자체가 어뷰징 신호라서 오히려 저품질 위험을 키운다. 위험 표현은 숨기는 게 아니라 **더 구체적이고 정직한 문장으로 바꾸는 것**이 유일한 안전한 방법이다. 바꿀 수 없는 주장(사실이 아니거나 근거가 없는 주장)이면 그 문장을 삭제한다.

**후기글 특칙**: 화자가 방문객이므로 치환 문장도 **방문객 말투**로 바꾼다. 센터 말투("저희는 ~합니다")로 치환하면 화자가 무너진다. 예: "최고의 시설" → (센터판) "웨이트 머신 60대를 보유한" / (후기판) "가서 세어보니 웨이트 머신이 60대쯤 되더라고요".

---

## A. 최상급·단정 표현

근거를 제시할 수 없는 최상급은 표시광고법상 과장광고 소지가 있고, 네이버도 광고성 문서 신호로 본다. **구체적 사실·수치로 바꾸면 설득력은 오히려 올라간다.**

| 위험 표현 | 이렇게 바꾼다 (후기 화자 기준) |
|---|---|
| 최고의 시설, 최상급 | "직접 보니 천국의 계단이 4대라 대기 없이 바로 탔어요" — 관찰한 스펙으로 |
| 지역 1위, No.1 | "28년 넘게 한자리에서 하셨다고 들었어요" — 들은 사실로 |
| 최저가, 파격가, 반값 | "가격은 상담 때 안내받았는데, 생각보다 부담이 덜했어요" |
| 유일한, 독보적인 | "이 근처에서 프리웨이트실이 따로 있는 데는 흔치 않더라고요" |
| 100% 만족, 완벽한 | "제 기준에선 ○○ 부분이 제일 만족스러웠어요" — 개인 의견으로 한정 |
| 무조건, 절대, 확실히 | 삭제하고 본인 경험 서술로 |
| 여기가 정답, 여기로 가세요 | "저는 여기로 정했어요" — 권유가 아니라 본인 선택으로 |

## B. 효과 보장·수치 단정 (다이어트)

체중 감량을 기간·수치로 보장하는 표현은 과장광고의 대표 유형이고, 신고당하기도 가장 쉬운 표현이다. **후기 화자가 말해도 광고 규제 대상은 동일하다.**

| 위험 표현 | 이렇게 바꾼다 |
|---|---|
| 한 달 5kg 감량 보장 | 삭제. 보장은 화자가 누구든 쓸 수 없다 |
| 여기 다니면 확실히 빠져요 | "저는 이제 시작이라 결과는 더 지켜봐야죠" |
| 누구나 살 빠지는 | 삭제 → 본인이 왜 여기서 하기로 했는지로 대체 |
| ○주 만에 이런 변화 | 본인 실제 경험이 아니면 쓰지 않는다. 써도 "개인차가 있어요" 병기 |

## C. 의료·치료성 표현

헬스장은 의료기관이 아니므로 진단·치료를 연상시키는 단어는 의료법 오인 위험이 있다. **"치료"라는 단어 자체를 쓰지 않는다.**

| 위험 표현 | 이렇게 바꾼다 |
|---|---|
| 통증 치료, 디스크 치료 | "허리가 안 좋다고 말씀드렸더니 무리 없는 강도부터 안내해주시더라고요" |
| 재활 치료, 교정 치료 | "운동 목적으로 자세를 잡아가는 정도" |
| 완치, 낫는다 | 쓰지 않는다 (대체 불가 — 문장 삭제) |
| 체형 교정 (단정형) | "자세를 같이 봐주신다고 하셨어요" 정도의 과정 서술로 |

## D. 상업 단어 빈도 (도배 방지) — **후기글은 기준을 더 엄격히**

후기 형식인데 홍보 문구가 반복되면 "위장 광고"로 읽혀 일반 홍보글보다 감점 폭이 크다.

- **할인, 특가, 이벤트, 무료, 혜택**: 각 단어 글 전체 **1회 이내** (센터판은 1~2회, 후기판은 더 줄인다). 이벤트 섹션(6단계)에만 몰고, 공감·방문후기·신뢰 구간(3~5단계)에는 넣지 않는다.
- **전화번호**: 글 전체 1회 — 마무리 섹션(7단계)에만. 후기 화자가 전화번호를 본문 중간에 반복하면 광고 티가 가장 크게 난다.
- **가격 숫자 나열 금지**: "3개월 ○○원" 식 가격표는 쓰지 않는다. "상담 때 안내받았어요"로 넘긴다.
- **외부 링크 1~2개** (예약 링크 포함해서 계산).

## E. 절대 금지 (치환 불가 — 발견 즉시 삭제)

- **변칙 표기**: 특수문자 끼워넣기(이.벤.트), 자모 분리(할ㅇl인), 이미지 속 텍스트로 금칙어 숨기기
- **창작된 긴급성**: 이벤트 정보에 없는 마감일·선착순 인원 만들어내기
- **타 업체 비방·비교**: "다른 헬스장 다녀봤는데 거긴 별로고" 류 전부. 후기 화자는 비교 후기를 쓰고 싶은 유혹이 크지만, 실명·특정 가능한 비교는 명예훼손·비교광고 리스크다. 비교하려면 "예전에 다니던 곳"처럼 특정 불가능하게, 그것도 비방 없이.
- **없는 경험·사례 창작**: 화자가 실제로 겪지 않은 일(PT 받은 이야기, 몇 달 다닌 이야기)을 지어내지 않는다. stores.md에 트레이너 정보가 없으면 PT 후기를 만들지 않는다.

## F. 후기글 전용 — 대가성·진정성 검수 (이 스킬에만 있는 항목)

| 점검 | 기준 |
|---|---|
| 대가성 표기 | 협찬·제공·원고료를 받았다면 **글 상단(첫 화면)**에 명확히 표기됐는가. 해시태그에 `#협찬후기` 또는 `#광고` 포함됐는가 |
| 표기 은폐 | 표기가 맨 아래에만 있거나, 흐린 표현("잘 다녀왔습니다" 류)으로 뭉개지 않았는가 |
| 허위 내돈내산 | 대가를 받았는데 "제 돈 주고" 류 표현을 쓰지 않았는가 (**적발 시 가장 큰 리스크**) |
| 솔직한 아쉬움 | 가벼운 단점이 1~2개 들어 있는가 (0개면 광고로 읽힘) |
| 화자 일관성 | 중간에 "저희 센터" 같은 센터 말투로 새지 않았는가 |
| 경험 창작 | 주어진 정보 밖의 경험을 지어내지 않았는가 |

## 검수 절차

1. 초안 완성 후 A~F 카테고리 순서로 전체 스캔.
2. 발견 표현은 위 치환 방향대로 수정. 치환할 사실적 근거가 없으면 문장 삭제.
3. 완료 후 한 줄 보고: `위험 표현 검수: N건 치환 (예: "최고의 시설" → 관찰 스펙 서술), 삭제 M건 / 대가성 표기: 있음(상단)·해당없음`
4. 0건이면 "위험 표현 검수: 통과"로 보고하되, **F항목(대가성·화자 일관성)은 매번 명시적으로 보고**한다.
