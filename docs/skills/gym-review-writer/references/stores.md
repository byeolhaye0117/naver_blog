# 지점 정보

글 작성 시 사용자가 말한 지점명에 해당하는 블록만 읽어 사용한다. 여기에 **없는 항목은 지어내지 않는다** (예: 트레이너 정보가 비어 있으면 트레이너 관련 서술을 만들지 않고, 시설·운영 원칙·강점으로 신뢰 구간을 채운다).
이벤트와 함께 찾는 키워드는 여기에 저장하지 않는다. 이벤트는 매 글 작성 시 텍스트로, 함께 찾는 키워드는 이미지로 받는다.

**정식 상호명 (필수)**: 각 지점 블록의 `정식 상호명` 항목을 쓴다. **횟수는 글 유형마다 다르다 — 앱 검수 기준(`lib/writing/checker.ts` 의 `SPECS`)과 같은 값이다**: 홍보글 3회 이상 · 정보글 2회 이상 · **후기글은 횟수를 요구하지 않는다**(방문객이 상호를 반복하면 광고 티가 나므로 앱도 0으로 둔다 — 다만 **적어도 처음 나올 때 한 번은 정식 상호명으로** 밝힌다).

**줄여 쓰지 않는다**: 「두정점입니다」처럼 지역명+점 으로만 쓰면 독자가 어느 브랜드인지 모른다. 브랜드가 남는 축약(「착한헬스 두정점」)은 괜찮다 — 아래 여성전용 규칙과 같다. 앱 검수의 `legalNameShort` 가 같은 기준으로 본다.

**정식 상호명에 "여성전용"이 들어 있는 지점 (지점 블록의 `정식 상호명` 을 보고 판단한다 — 회원이 앱에서 고치면 해당 지점이 바뀌므로 이름을 박아두지 않는다. 상호명에 "여성전용"이 없어도 **여성전용 지점** 표시가 붙은 곳은 남성 대상 표현을 쓰지 않는다) 사용 규칙**:
- **첫 등장(후킹)은 정식 명칭 그대로** 쓴다 — "여성전용 착한헬스 두정점". 여성전용이라는 사실이 이 지점의 최대 강점이므로 첫 노출에서 확실히 각인시킨다.
- **이후 2회는 "착한헬스 두정점"으로 줄여도 된다.** 후기 화자가 정식 명칭을 세 번 다 읊으면 광고 티가 가장 크게 난다 — 실제 방문객은 그렇게 말하지 않는다. 축약형도 상호명 카운트에 포함한다.
- 여성전용이라는 속성은 상호 반복이 아니라 **본문 내용(얼굴인식 출입, 남성 없는 환경, 새벽 안심)을 화자가 직접 겪은 것으로** 체감시킨다.
