# 발행 기록 (post log) — 후기글

후기 글 간 유사성 방지용 장부. 글을 쓸 때마다 한 줄씩 쌓는다.

스킬 파일을 직접 수정할 수 없는 환경에서는 이 파일이 비어 있을 수 있다. 그 경우 글 완성 시 출력되는 기록 한 줄을 **사용자가 보관**했다가, 다음 글 요청 때 함께 붙여넣는 방식으로 운영한다. 사용자가 붙여넣은 기록은 이 파일의 기록과 동일하게 취급한다.

**중요**: 후기글과 홍보글(gym-blog-writer)은 **같은 블로그에 발행되면 유사문서 판정을 공유한다.** 같은 지점의 홍보글 기록이 있으면 함께 확인해서 메인 키워드·소제목·앵글이 겹치지 않게 한다. 홍보글 기록도 이 파일에 함께 적어두면 관리가 쉽다 (유형 칸에 [홍보]/[후기] 표기).

**형식:**
```
날짜 | [유형] | 지점 | 메인 키워드 | 도입 유형 | 주력 앵글 | 대가성 | 소제목 목록
```

**예시:**
```
2026-07-24 | [후기] | 쌍용점 | 쌍용동 24시헬스장 | 도입②결심계기 | 앵글:시간 | 내돈내산 | 소제목: 세 번 가고 끝난 작년 등록비 / 문 열려 있나 확인하러 갔다가 / 계단 4대를 보고 마음이 기울었다 / 아쉬웠던 한 가지 / 저는 이렇게 예약했어요
```
