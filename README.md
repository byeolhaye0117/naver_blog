# 네이버 블로그 상위노출 매니저

헬스장·피트니스 네이버 블로그를 **상위노출 관점에서 조사 → 작성 → 검수 → 발행 → 순위관리**까지
한곳에서 굴리는 웹앱입니다. PC·태블릿·휴대폰에서 모두 쓸 수 있게 만들었습니다.

## 빠르게 시작

```bash
npm install
npm run dev
```

→ 브라우저에서 http://localhost:3000

**휴대폰·태블릿에서 쓰려면** 같은 와이파이에 연결한 뒤, PC의 내부 IP로 접속하세요.
(예: `http://192.168.0.10:3000` — IP는 macOS `ifconfig | grep "inet "`, Windows `ipconfig` 로 확인)
개발 서버가 `0.0.0.0` 으로 열려 있어 별도 설정이 필요 없습니다.

API 키는 없어도 전부 동작합니다. 키가 없으면 숫자가 **샘플 데이터**로 표시되고 화면에도 그렇게 안내됩니다.
실제 네이버 데이터로 바꾸려면 [`.env.example`](.env.example) 을 `.env.local` 로 복사해 값을 채우세요
(앱 안 **가이드 → API 키 설정** 에 발급 절차가 정리되어 있습니다).

## 화면 구성

| 화면 | 하는 일 |
|---|---|
| **대시보드** | 발행 균형(정보:홍보 2:1)·발행 주기·순위 변동·지금 할 일 |
| **키워드 조사** | 월간 검색량 + 블로그 발행량으로 **경쟁률**을 계산해 등급 판정. 지역 키워드 조합 생성기, 13개월 검색 추이 |
| **상위노출 분석** | 그 키워드로 지금 상위에 있는 글들을 뜯어 제목 길이·키워드 위치·최신성·공통 소재를 읽고 **"무엇을 맞춰야 하는지"** 처방으로 번역 |
| **글 작성** | 유형별(홍보/정보/후기) 골격 생성 + **실시간 검수** (키워드 횟수·밀도·등간격 패턴·금칙어·이미지 배치·AI 티) |
| **발행 관리** | 초안→검수완료→발행완료 상태 관리, 발행 기록 한 줄 뽑기 |
| **순위 추적** | (키워드 + 내 글 URL) 등록 후 조회할 때마다 순위를 기록해 추이 그래프로 |
| **지점 정보** | 정식 상호명·지역 키워드·시설·강점·연락처. **여기에 없는 정보는 글에 지어내지 않는다**는 원칙의 기준점 |
| **가이드** | C-Rank / D.I.A.+ / 스마트블록, 저품질 트리거, 유형별 수치 기준, 위험 표현 치환표, API 키 발급 |

## 발행(업로드)은 왜 자동이 아닌가

**네이버는 블로그 글쓰기 공식 API를 제공하지 않습니다.** 로그인을 자동화해 우회하는 방법이 있지만
캡차·2단계 인증에 막히고 계정 제재 위험이 있습니다. 그래서 이 앱은 대신 **발행 패키지**를 만들어 줍니다:

1. 제목 (복사)
2. 본문 — 작성 안내와 이미지 지시문이 빠진 상태 (복사)
3. 이미지 배치표 — 몇 번째에 무엇을, 어떤 파일명·대체텍스트로
4. 해시태그 (복사)
5. 발행 체크리스트 — 색인 요청, 지도 첨부, 발행 후 24시간 주의사항까지
6. 발행 기록 한 줄 — 다음 글 쓸 때 붙여넣으면 소재·앵글이 겹치지 않게 잡아줍니다

네이버 에디터를 열고 위에서부터 순서대로 붙이면 끝입니다.

## 검수 기준은 어디서 왔나

`gym-blog-writer` / `gym-info-writer` / `gym-review-writer` Claude 스킬의 규칙표를 코드로 옮긴 것입니다.
유형별 수치는 [`lib/writing/checker.ts`](lib/writing/checker.ts) 의 `SPECS`, 위험 표현 사전은
[`lib/writing/banned.ts`](lib/writing/banned.ts) 에 있고, 앱의 **가이드** 화면이 같은 값을 표로 보여줍니다.

| 항목 | 홍보글 | 정보글 | 후기글 |
|---|---|---|---|
| 메인 키워드 | 5~7회 | 3~5회 | 3~5회 |
| 키워드 밀도 | 2% 이내 | 1.8% 이내 | 1.5% 이내 |
| 본문 글자수 | 1,900~2,100 | 1,900~2,600 | 1,900~2,100 |
| 정식 상호명 | 3회 이상 | — | — |
| 제목 | 28~40자 | 28~40자 | 28~40자 + "후기" |

검수는 표현을 안전하게 바꾸는 것이지 홍보를 약하게 만드는 게 아닙니다.
**철자를 바꿔 숨기는 것(`최.고`, `할ㅇl인`)은 그 자체가 어뷰징 신호**라 오히려 위험이 커집니다 —
앱도 이걸 따로 잡아냅니다.

## Claude 스킬과 함께 쓰기

이 앱은 **조사·검수·관리** 도구이고, 본문을 실제로 써주는 건 Claude 스킬입니다.

1. 이 앱에서 키워드를 고르고 상위노출 분석으로 처방을 받는다
2. Claude에게 요청한다 — 예: `"쌍용점 홍보글 써줘, 메인 키워드는 쌍용동 24시헬스장, 이벤트는 …"`
3. 결과를 이 앱 **글 작성** 에 붙여넣으면 실시간 검수가 돌아간다
4. **발행 패키지** 로 네이버에 올리고, **순위 추적** 에 등록한다

## 데이터 저장

작성한 글·순위 이력은 `data/db.json` 에만 저장됩니다 (git 에 올라가지 않음).
백업은 이 파일을 복사하면 되고, 저장 위치는 `NAVER_BLOG_DATA_DIR` 로 바꿀 수 있습니다.

> Vercel 등 파일 쓰기가 막힌 환경에 올리면 저장소가 자동으로 메모리로 바뀌며,
> 서버 인스턴스가 재시작될 때 데이터가 사라집니다. 기록을 남겨야 한다면 로컬에서 실행하세요.

## 개발

```bash
npm run dev        # 개발 서버 (0.0.0.0 바인딩 — 휴대폰 접속 가능)
npm run build      # 프로덕션 빌드
npm start          # 프로덕션 실행
npm run typecheck  # 타입 검사
npm test           # 검수 로직 테스트 (추가 의존성 없음)
```

`npm test` 는 `lib/` 의 검수·분석 로직을 검증합니다 — 본문 파싱, 키워드 카운트(띄어쓰기 무시),
위험 표현·변칙 표기 탐지, 유형별 기준 판정, 골격→복사 패키지 변환, 협찬 표기, 등간격 패턴,
키워드 등급 분포 캘리브레이션.

**주의**: `lib/` 안의 **런타임** import 는 상대경로를 쓰세요 (`import type` 은 `@/` 별칭 사용 가능).
테스트 러너가 프레임워크 없이 `tsc` 로 컴파일해 돌리기 때문에 별칭은 해석되지 않습니다.

### 알려진 사항

`npm audit` 이 postcss·sharp 관련 high 취약점 3건을 보고합니다. 둘 다 Next.js 가 내부적으로
들고 있는 의존성이고 현재 모든 Next 버전이 영향 범위에 있어(권고안의 "fix"는 Next 9 로 다운그레이드)
그대로 두었습니다. 로컬 도구라 외부 입력을 받는 경로도 아닙니다.

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · 파일 기반 JSON 저장소.
